# Modern UI provenance notes

The Batch 27 modern UI set is original project-owned geometry generated by
`tools/reforged-assets/create-modern-ui-sources.mjs`. No external image,
third-party archive, font file, trademark, franchise reference, or Batch 25
golden pixel is an input.

The generated `modern-ui.core.json` report beside this note is the complete
machine provenance record for the committed manifest, canonical source PNGs,
runtime atlas, and hashes. Runtime redistribution contains only the generated
atlas PNG and runtime-safe import JSON.
